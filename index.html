How it works

每個好勢科技的產品，都建立在嚴謹的技術架構之上。

Every Ho-sè product is built on a rigorous technical foundation.

🧠

AI 風險評估引擎

AI Risk Assessment Engine

責任鏈式三道過濾器：方向向量分析 → 橫向速度分解 → 3D 未來路徑預測。誤報率低，100ms 內完成風險評估。

A three-stage chain-of-responsibility pipeline: heading vector → lateral velocity → 3D path prediction. Fast, precise, low false-alert rate.

Go · PostGIS · Redis
📍

3D 空間感知

3D Spatial Awareness

利用 GPS 海拔數據進行三維碰撞預測，能正確區分天橋上的行人與地面車輛，大幅降低誤報率。

GPS altitude data enables true 3D collision modeling — correctly distinguishing a pedestrian on an overpass from a car below, cutting false alerts significantly.

CoreLocation · PostGIS
🔔

Critical Alert 推播

Critical Alert Push

突破 iOS 靜音限制的緊急推播機制，搭配自訂警報音效與全螢幕震動 UI，確保警報在任何情況下都不被忽略。

Apple's Critical Alert entitlement lets us bypass silent mode entirely — paired with a custom alarm sound and full-screen UI that simply cannot be ignored.

Firebase FCM · APNs
☁️

彈性雲端架構

Elastic Cloud Infrastructure

部署在 Google Cloud Run，流量少的時候幾乎不花錢，用戶變多時自動增加伺服器應付，不需要手動管理。GitHub Actions 自動化部署，每次更新穩定可靠。

Deployed on Google Cloud Run — costs nearly nothing when quiet, scales up automatically as users grow, with zero manual server management. CI/CD via GitHub Actions.

Cloud Run · Docker · GCP
📊

軌跡數據分析

Trajectory Data Analysis

Redis 快取每位用戶最近 10 筆軌跡點，搭配 Python 分析管道進行 EDA 與模型調優，持續降低誤報率。

Redis caches each user's last 10 GPS points for real-time prediction. A Python analysis pipeline handles EDA and model tuning to continuously reduce false alerts.

Python · Pandas · GeoPandas
🤖

ML 升級路線

Next-Gen ML Roadmap

下一代將導入 Transformer-based 軌跡預測模型，以 GPU 加速推論，取代現有規則式引擎，進一步大幅降低誤報率。

Next generation will replace rule-based filters with a Transformer-based trajectory model, GPU-accelerated via TensorRT — dramatically improving accuracy and further reducing false alerts.

PyTorch · TensorRT · NVIDIA
